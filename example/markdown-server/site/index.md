# Hello from Joyeer

This page is a Markdown file, turned into HTML by a Joyeer program on every
request. There is no framework, no template engine and no garbage collector.

## Pages

- [About this server](/about)
- [Documentation](/docs/)
- [What the renderer supports](/docs/markdown)

## Try it

Edit any file under `site/` and reload the page. The server reads the file
again for each request, so there is nothing to rebuild.
