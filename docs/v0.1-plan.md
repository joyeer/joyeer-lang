# Joyeer v0.1 — Implementation Plan

## Goal

Build a minimal language (implemented in Rust) that can write a zero-overhead JSON parser,
comparable to C/C++/Rust in performance.

---

## Target: JSON Parser in Joyeer

A JSON parser needs these language capabilities:

| Requirement | Language Feature Needed |
|-------------|------------------------|
| Read string/file content | String type + File I/O |
| Iterate characters | Char type + index access |
| Branch on character `{`, `[`, `"` | Pattern matching / if-else |
| Represent JSON values | Enum (algebraic types) |
| Store key-value pairs | Map (hash map) |
| Store arrays | Dynamic Array |
| Recursive parsing | Recursive functions |
| Report errors | Result type or Option |
| Output results | print / string formatting |

---

## Language Feature Checklist

### Must Have

- [x] `let` / `var` (immutable / mutable bindings)
- [x] `Int` type (64-bit signed integer)
- [x] `Bool` type
- [x] `String` type
- [ ] `Char` type (single character)
- [x] Function definition and calls
- [x] `if / else if / else`
- [x] `while` loop
- [x] `return`
- [ ] `struct` (value types with named fields)
- [ ] `enum` + pattern matching (`match`)
- [ ] Dynamic `Array<T>`
- [ ] `Map<String, T>` (hash map)
- [ ] String methods: `len()`, `charAt()`, `substring()`
- [ ] `nil` / `Option<T>`
- [x] `print`

### Nice to Have

- [ ] Basic generics (`Array<T>`, `Map<K,V>`)
- [ ] File read (`readFile()`)
- [ ] `Float` / `Double` type
- [ ] `Result<T, E>` error handling

### Not Needed Yet

- Closures / Lambdas
- Traits / Interfaces
- Concurrency
- Module system (single file is enough)

## Target Code Example

What a JSON parser should look like in Joyeer v0.1:

```
// main.joyeer

enum JsonValue {
    Null,
    Bool(Bool),
    Number(Int),
    Str(String),
    Array(Array<JsonValue>),
    Object(Map<String, JsonValue>),
}

struct Parser {
    var input: String
    var pos: Int
}

func newParser(input: String): Parser {
    return Parser { input: input, pos: 0 }
}

func peek(p: &Parser): Char {
    return p.input.charAt(p.pos)
}

func advance(p: &mut Parser): Char {
    let ch = p.input.charAt(p.pos)
    p.pos = p.pos + 1
    return ch
}

func skipWhitespace(p: &mut Parser) {
    while p.pos < p.input.len() {
        let ch = peek(p)
        if ch != ' ' && ch != '\n' && ch != '\t' && ch != '\r' {
            return
        }
        p.pos = p.pos + 1
    }
}

func parseValue(p: &mut Parser): JsonValue {
    skipWhitespace(p)
    let ch = peek(p)
    if ch == '"' {
        return parseString(p)
    } else if ch == '{' {
        return parseObject(p)
    } else if ch == '[' {
        return parseArray(p)
    } else if ch == 't' || ch == 'f' {
        return parseBool(p)
    } else if ch == 'n' {
        return parseNull(p)
    } else {
        return parseNumber(p)
    }
}

func main() {
    let input = '{"name": "joyeer", "version": 1}'
    var p = newParser(input)
    let value = parseValue(&mut p)
    print(value)
}
```

### Project Structure

### Implementation Phases

#### Phase 1: Lexer + Parser

```
Input:  Joyeer source code string
Output: AST

Tasks:
├── Token definition (Rust enum — perfect for this)
├── Lexer: source → token stream
│   ├── Keywords: let, var, func, if, else, while, return,
│   │            struct, enum, match, true, false, nil
│   ├── Operators: + - * / % == != < <= > >= && || ! = & .
│   ├── Delimiters: { } ( ) [ ] : , -> ;
│   ├── Literals: integers, floats, strings, chars
│   └── Identifiers
├── AST definition (Rust enum + struct)
│   ├── Declarations: FuncDecl, StructDecl, EnumDecl, VarDecl, LetDecl
│   ├── Statements: IfStmt, WhileStmt, ReturnStmt, ExprStmt, MatchStmt
│   └── Expressions: Binary, Unary, Call, FieldAccess, Index, Literal, Var
├── Parser: token stream → AST (recursive descent)
└── Pretty printer: AST → readable output (for debugging)
```

#### Phase 2: Type Checking

```
Input:  AST
Output: Type-annotated AST

Tasks:
├── Symbol table (HashMap-based scope chain)
├── Type inference for local variables
├── Type checking
│   ├── Function parameter types
│   ├── Return type matching
│   ├── Assignment type compatibility
│   ├── Binary operator type rules
│   ├── Struct field types
│   └── Enum variant types
├── Let immutability enforcement
└── Error reporting with source locations (line, column)
```

#### Phase 3: LLVM Code Generation

```
Input:  Type-checked AST
Output: Executable binary

Tasks:
├── Integrate inkwell crate (Rust LLVM bindings)
├── Type mapping
│   ├── Int    → i64
│   ├── Bool   → i1
│   ├── Char   → i8 (or i32 for Unicode)
│   ├── String → { i8*, i64 } (pointer + length)
│   ├── Struct → LLVM StructType
│   └── Enum   → tagged union { i8 tag, [largest_variant] data }
├── Function generation → LLVM Function + BasicBlocks
├── Control flow
│   ├── if/else → conditional branch + BasicBlocks
│   ├── while   → loop BasicBlocks + branch
│   └── match   → switch or chained branches
├── Struct operations
│   ├── Construction → alloca + store fields
│   ├── Field access → GEP (GetElementPtr)
│   └── Mutation    → store to field
├── Enum operations
│   ├── Construction → set tag + store variant data
│   └── Match       → load tag + switch
└── Link with C runtime → output executable
```

```
Minimal C runtime linked into every Joyeer program:

runtime/

├── string.c                 // String operations

│   ├── joyeer_array_get(arr, index) → Value

│   └── joyeer_array_len(arr) → Int

│   ├── joyeer_map_create() → Map

│   ├── joyeer_map_get(map, key) → Option<Value>

#### Phase 5: Validation

```
Write a JSON parser in Joyeer and verify:
├── Correctly parses JSON strings, numbers, bools, null
├── Correctly parses JSON arrays and objects
├── Correctly handles nested structures
├── Correctly reports parse errors

## Zero-Overhead Design Decisions

| Decision | Approach |
|----------|----------|
| **String** | Pointer + length, no null-terminator, no GC |
| **Struct** | Stack-allocated by default, pass by value (small) or reference |
| **Enum** | Tagged union, size = tag + largest variant, stack-allocated |
| **Array** | Heap-allocated buffer with capacity doubling, manual free |
| **Map** | Open-addressing hash map, heap-allocated, manual free |
| **Memory** | Manual malloc/free via runtime, no GC in v0.1 |
| **Function calls** | Direct calls, no vtable dispatch |
| **References** | `&T` (immutable) and `&mut T` (mutable), second-class (cannot store) |
